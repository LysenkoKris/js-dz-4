# Домашнее задание 4

- `src/heap.ts` — куча Min Heap / Max Heap, push и pop O(log n), peek O(1)
- `src/heapSort.ts` — пирамидальная сортировка, O(n log n), память O(1)
- `src/topK.ts` — топ-k сверху и снизу через кучу, O(n log k), память O(k)
- `src/priorityQueue.ts` — очередь с приоритетом на куче, enqueue и dequeue O(log n)
- `src/compare.ts` — сравнение элементов любого типа (вариант для тех, кого не было на лекции)

Установка:

```bash
bun install
```

Запуск (меню, данные вводятся с клавиатуры):

```bash
bun run index.ts
```

Тесты:

```bash
bun test
```
